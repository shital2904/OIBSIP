# Number Guessing Game

## Internship

This project was developed as part of my Java Development Internship at Oasis Infobyte.

## Description

The Number Guessing Game is a Java console-based application where the computer generates a random number and the user tries to guess it.

The program gives hints to the user whether the guessed number is higher or lower than the generated number and keeps track of the number of attempts.

## Features

- Generates a random number
- Accepts user guesses
- Provides higher or lower hints
- Counts the number of attempts
- Displays the final result

## Technologies Used

- Java
- Scanner
- Random

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run the Java program.
3. Enter your guess in the console.
4. Follow the hints until you guess the correct number.
